# Unidos 💕

App para Diego y Bianka (Lima ↔ Gotemburgo). Calendario, horarios, dates, diario y recuerdos.

**URL:** https://diegovh03.github.io/Unidos/

## En el iPhone

1. Abrir el enlace **solo en Safari**
2. Compartir → **Agregar a pantalla de inicio**
3. Elegir si eres Diego o Bianka la primera vez

Los datos (fotos, diario, notas) se quedan en el celular. No se envían a internet.
